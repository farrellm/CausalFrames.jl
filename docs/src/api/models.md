# Model fitting (MLJ)

With MLJ loaded (`using MLJ`), the [`FitModel`](@ref "FitModel") summarizer
fits a model inside any summarizing transform, emitting
[`FittedModel`](@ref)s. These operators apply such models and read their
diagnostics.
